# Modelo de Datos - Sistema de Ventas con Control de Lotes

## Entidades Principales

### 1. **Productos**
```sql
CREATE TABLE productos (
    id_producto INT PRIMARY KEY AUTO_INCREMENT,
    codigo_producto VARCHAR(50) UNIQUE NOT NULL,
    nombre VARCHAR(255) NOT NULL,
    descripcion TEXT,
    categoria_id INT,
    unidad_medida VARCHAR(20), -- 'unidad', 'kg', 'litro', etc.
    estado ENUM('activo', 'inactivo') DEFAULT 'activo',
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2. **Lotes de Inventario**
```sql
CREATE TABLE lotes_inventario (
    id_lote INT PRIMARY KEY AUTO_INCREMENT,
    producto_id INT NOT NULL,
    numero_lote VARCHAR(100) NOT NULL,
    precio_compra DECIMAL(10,2) NOT NULL,
    cantidad_inicial INT NOT NULL,
    cantidad_disponible INT NOT NULL,
    fecha_compra DATE NOT NULL,
    fecha_vencimiento DATE,
    proveedor_id INT,
    numero_factura_compra VARCHAR(100),
    costo_adicional DECIMAL(10,2) DEFAULT 0, -- fletes, impuestos, etc.
    estado ENUM('disponible', 'agotado', 'vencido') DEFAULT 'disponible',
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (producto_id) REFERENCES productos(id_producto),
    UNIQUE KEY unique_lote_producto (producto_id, numero_lote)
);
```

### 3. **Ventas (Cabecera)**
```sql
CREATE TABLE ventas (
    id_venta INT PRIMARY KEY AUTO_INCREMENT,
    numero_factura VARCHAR(100) UNIQUE NOT NULL,
    cliente_id INT,
    fecha_venta DATETIME NOT NULL,
    subtotal DECIMAL(12,2) NOT NULL,
    impuestos DECIMAL(12,2) DEFAULT 0,
    descuento DECIMAL(12,2) DEFAULT 0,
    total DECIMAL(12,2) NOT NULL,
    metodo_pago VARCHAR(50),
    estado ENUM('pendiente', 'pagada', 'anulada') DEFAULT 'pendiente',
    vendedor_id INT,
    observaciones TEXT,
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 4. **Detalle de Ventas por Lote**
```sql
CREATE TABLE detalle_ventas_lote (
    id_detalle INT PRIMARY KEY AUTO_INCREMENT,
    venta_id INT NOT NULL,
    producto_id INT NOT NULL,
    lote_id INT NOT NULL,
    cantidad_vendida INT NOT NULL,
    precio_venta_unitario DECIMAL(10,2) NOT NULL,
    precio_compra_unitario DECIMAL(10,2) NOT NULL, -- del lote
    subtotal DECIMAL(12,2) NOT NULL, -- cantidad * precio_venta
    ganancia_unitaria DECIMAL(10,2) GENERATED ALWAYS AS (precio_venta_unitario - precio_compra_unitario) STORED,
    ganancia_total DECIMAL(12,2) GENERATED ALWAYS AS (cantidad_vendida * (precio_venta_unitario - precio_compra_unitario)) STORED,
    
    FOREIGN KEY (venta_id) REFERENCES ventas(id_venta),
    FOREIGN KEY (producto_id) REFERENCES productos(id_producto),
    FOREIGN KEY (lote_id) REFERENCES lotes_inventario(id_lote)
);
```

### 5. **Entidades Complementarias**

#### Clientes
```sql
CREATE TABLE clientes (
    id_cliente INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(255) NOT NULL,
    email VARCHAR(255),
    telefono VARCHAR(20),
    direccion TEXT,
    documento VARCHAR(50),
    tipo_documento VARCHAR(20),
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### Proveedores
```sql
CREATE TABLE proveedores (
    id_proveedor INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(255) NOT NULL,
    contacto VARCHAR(255),
    email VARCHAR(255),
    telefono VARCHAR(20),
    direccion TEXT,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## Consultas Importantes para Análisis de Ganancias

### 1. Ganancia por Venta Específica
```sql
SELECT 
    v.numero_factura,
    v.fecha_venta,
    c.nombre as cliente,
    p.nombre as producto,
    l.numero_lote,
    dvl.cantidad_vendida,
    dvl.precio_compra_unitario,
    dvl.precio_venta_unitario,
    dvl.ganancia_unitaria,
    dvl.ganancia_total
FROM detalle_ventas_lote dvl
JOIN ventas v ON dvl.venta_id = v.id_venta
JOIN productos p ON dvl.producto_id = p.id_producto
JOIN lotes_inventario l ON dvl.lote_id = l.id_lote
LEFT JOIN clientes c ON v.cliente_id = c.id_cliente
WHERE v.id_venta = ?;
```

### 2. Ganancia por Producto en un Período
```sql
SELECT 
    p.nombre as producto,
    SUM(dvl.cantidad_vendida) as total_vendido,
    AVG(dvl.precio_compra_unitario) as precio_compra_promedio,
    AVG(dvl.precio_venta_unitario) as precio_venta_promedio,
    SUM(dvl.ganancia_total) as ganancia_total,
    AVG(dvl.ganancia_unitaria) as ganancia_promedio_unitaria
FROM detalle_ventas_lote dvl
JOIN ventas v ON dvl.venta_id = v.id_venta
JOIN productos p ON dvl.producto_id = p.id_producto
WHERE v.fecha_venta BETWEEN ? AND ?
GROUP BY dvl.producto_id, p.nombre
ORDER BY ganancia_total DESC;
```

### 3. Rentabilidad por Lote
```sql
SELECT 
    p.nombre as producto,
    l.numero_lote,
    l.precio_compra,
    l.cantidad_inicial,
    l.cantidad_disponible,
    (l.cantidad_inicial - l.cantidad_disponible) as cantidad_vendida,
    COALESCE(SUM(dvl.ganancia_total), 0) as ganancia_obtenida,
    CASE 
        WHEN l.cantidad_disponible = 0 THEN 'Agotado'
        WHEN l.cantidad_disponible > 0 THEN 'Disponible'
    END as estado_lote
FROM lotes_inventario l
JOIN productos p ON l.producto_id = p.id_producto
LEFT JOIN detalle_ventas_lote dvl ON l.id_lote = dvl.lote_id
GROUP BY l.id_lote, p.nombre, l.numero_lote, l.precio_compra, l.cantidad_inicial, l.cantidad_disponible
ORDER BY ganancia_obtenida DESC;
```

## Triggers para Mantener Consistencia

### 1. Actualizar Inventario Disponible
```sql
DELIMITER //
CREATE TRIGGER actualizar_inventario_venta
AFTER INSERT ON detalle_ventas_lote
FOR EACH ROW
BEGIN
    UPDATE lotes_inventario 
    SET cantidad_disponible = cantidad_disponible - NEW.cantidad_vendida,
        estado = CASE 
            WHEN cantidad_disponible - NEW.cantidad_vendida <= 0 THEN 'agotado'
            ELSE 'disponible'
        END
    WHERE id_lote = NEW.lote_id;
END//
DELIMITER ;
```

## Consideraciones Adicionales

1. **Control FIFO/LIFO**: Puedes agregar un campo `metodo_salida` en la tabla productos para definir si usar FIFO o LIFO por producto.

2. **Costos Adicionales**: El campo `costo_adicional` en lotes permite incluir fletes, seguros, etc., para un cálculo más preciso de la ganancia.

3. **Auditoría**: Considera agregar tablas de auditoría para rastrear cambios en precios y movimientos de inventario.

4. **Alertas de Vencimiento**: Puedes crear vistas o procedimientos para alertar sobre productos próximos a vencer.

5. **Reportes de Rotación**: Este modelo permite calcular la rotación de inventario por lote y producto.

Este modelo te permitirá tener un control preciso de tus ganancias por cada artículo vendido, considerando el precio específico del lote del cual se vendió el producto.
